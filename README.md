# 💻 Lógica de Programação — Engenharia de Software

Este repositório tem como objetivo documentar minha jornada de aprendizado em **Lógica de Programação**, como parte da graduação em Engenharia de Software.

Os estudos serão desenvolvidos por meio de conceitos teóricos, exercícios práticos, algoritmos e pequenos projetos, utilizando inicialmente a linguagem **C**.

A proposta é construir uma base sólida em pensamento computacional, resolução de problemas e desenvolvimento de algoritmos, preparando-me para trabalhar futuramente com tecnologias como Python, Java, JavaScript e desenvolvimento Full Stack.

## 🎯 Objetivos

- Desenvolver o raciocínio lógico e computacional.
- Aprender a estruturar algoritmos.
- Compreender os fundamentos da programação.
- Resolver problemas utilizando código.
- Desenvolver boas práticas de programação.
- Construir uma base para o desenvolvimento de software.

### 05. Estruturas de repetição
- `for`.

### 06. Vetores e matrizes
- Declaração e utilização de vetores.

### 07. Funções e procedimentos
- Criação de funções.
